# my_curriculum_vitae

Mein Lebenslauf wurde mit Bootstrap erstellt.

## Projekt anzeigen

Um den Lebenslauf im Datei `index.html` anzuzeigen:

Nachdem das Projekt heruntergeladen wurde, muss man:

* die notwendigen Ressourcen mit dem Befehl `npm install` im Terminal installieren;
* das Projekt mit `npm start` starten;
* den im Terminal angezeigten Link im Browser öffnen.

## Inhalt

Der Lebenslauf enthält mehrere Bereiche:

* einen Startbereich;
* eine persönliche Vorstellung;
* meine Kompetenzen;
* meine Ausbildung;
* meine akademischen und persönlichen Projekte;
* meine Erfahrungen;
* meine Sprachen, Interessen sowie sozialen Netzwerke und Kontaktinformationen.

## Verwendete Technologien

Ich habe verwendet:

* HTML für den Grundaufbau und die Anpassungen mit dem Framework;
* SCSS, um die Grundfarben zu ändern und einige Media Queries hinzuzufügen;
* Bootstrap als Framework;
* Bootstrap Icons, um die Seite mit passenden Icons zu verschönern;
* Vite;
* Git und GitHub für die Online-Veröffentlichung.
